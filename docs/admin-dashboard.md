# لوحة القيادة (Super Admin) — التشغيل

اللوحة على `/admin`، وما تشتغل قبل ثلاث خطوات. كل واحدة منها لازمة: بدون
الأولى ما فيه دالة تحسب، وبدون الثانية ما فيه من ينفّذها، وبدون الثالثة ما
فيه أحد له صلاحية يشوفها — حتى أنت.

---

## 1) القاعدة

شغّل `supabase/schema.sql` كامل على المشروع (SQL Editor في لوحة Supabase).
الملف كله idempotent (`create table if not exists` / `create or replace`)،
فتشغيله على قاعدة فيها بيانات ما يحذف شيئًا.

اللي يضيفه للّوحة تحديدًا:

| العنصر | وش يسوي |
|---|---|
| `app_admins` | من له صلاحية المالك. RLS مفعّل **بدون أي policy** — يعني ما يُقرأ ولا يُكتب إلا بمفتاح الخدمة من الخادم، فما فيه طريقة يمنح فيها مستخدم نفسه الصلاحية. |
| `ai_events` | سجل كل استدعاء نموذج: المزوّد، رقم المحاولة، نجح أو فشل، المدة، التوكينز. نفس الحماية. |
| `projects.prd_generated_at` | طابع زمني لأول توليد وثيقة. منه يُحسب «الوقت حتى الوثيقة» وعدد الوثائق في الفترة. |
| `admin_analytics()` | دالة `security definer` تحسب كل المؤشرات في استعلام واحد، ومسحوبة الصلاحية من `public` و`anon` و`authenticated`. |

> الوثائق اللي أُنشئت **قبل** هذي الخطوة ما لها `prd_generated_at`، فما
> تُحتسب ضمن أي فترة. اللوحة تذكر عددها صراحةً تحت بطاقة «وثائق مولَّدة»
> بدل ما تبلعها بصمت.

## 2) الدوال

```bash
supabase functions deploy admin-analytics   # جديدة
supabase functions deploy discovery         # صارت تكتب في ai_events
supabase functions deploy prd               # نفس الشيء
```

`admin-analytics` تحتاج `SUPABASE_SERVICE_ROLE_KEY` في بيئة الدوال (موجود
افتراضيًا في Supabase). قبل نشر `discovery` و`prd` بتظل صفحة «عمليات الذكاء
الاصطناعي» تقول «ما وصلت بيانات بعد» — وهذا صحيح، لأنه فعلًا ما فيه تتبّع.

## 3) صلاحيتك

هات معرّف حسابك ثم أضف الصف:

```sql
-- بدّل البريد ببريدك
insert into app_admins (user_id, is_super_admin)
select id, true from auth.users where email = 'you@example.com'
on conflict (user_id) do update set is_super_admin = true;
```

افتح `/admin`. أي حساب ثاني — مسجّل دخول أو لا — يشوف صفحة 404 عادية، والدالة
ترجّع 403 بدون أي تلميح إن اللوحة موجودة أصلًا.

## وش تعرضه اللوحة ووش لا

القاعدة الوحيدة اللي تحكم كل شيء هنا: **ما فيه رقم مُختلق**. المؤشر اللي
المنتج ما يقدر يقيسه يظهر «غير مُتتبَّع» مع سبب مكتوب، مو صفرًا.

| مُتتبَّع الآن | غير مُتتبَّع، ووش يلزمه |
|---|---|
| التسجيلات، المشاريع، المتطلبات، الأفواج | الزوّار ومصادر الزيارات — يحتاج مزوّد تحليلات |
| الوثائق ووقت التوليد | الإيراد والاشتراكات — يحتاج نظام فوترة |
| استدعاءات الذكاء الاصطناعي والمسار البديل | تقييم المستخدم — يحتاج 👍/👎 في شاشة الوثيقة |
| نسبة تعديل المتطلبات | إعادة التوليد — تحتاج حفظ إصدارات بدل الاستبدال |
| | نجاح تصدير PDF — التصدير داخل المتصفح بلا إشارة للخادم |
| | تكلفة الوثيقة — تحتاج سعرًا مضبوطًا لكل نموذج |

نفس الجدول معروض داخل اللوحة في **الإعدادات**، عشان السؤال «ليه هذا القسم
فاضي؟» يكون له جواب في المكان اللي يُسأل فيه.

### الفرق بين صفر ولا شيء

ثلاث حالات، وكل وحدة لها شكل مختلف على الشاشة:

- **`0`** — قياس حقيقي. ما صار شيء.
- **`—` + «ما وصلت بيانات بعد»** — نقيسه، بس العيّنة فاضية.
- **«غير مُتتبَّع» + سبب** — المنتج ما عنده وسيلة قياس أصلًا.

خلطها هو أسرع طريقة تخلي المالك يتصرّف بناءً على شيء ما حصل.

### الخصوصية

ما يوصل اللوحة أي بريد ولا اسم ولا عنوان مشروع ولا نص رسالة — الدالة ترجّع
أعدادًا ونِسبًا وفئات فقط. حتى «آخر حالات الفشل» تعرض نص الخطأ والمزوّد، بدون
أي محتوى من جلسة المستخدم. هذا حدّ مقصود: المالك يحتاج يعرف كيف يتصرّف
المنتج، مو وش كتب عميل معيّن.

### التنبيهات

مبنية على المؤشرات المتاحة فقط، وأسبابها مصاغة كاحتمال («قد يكون…») مو
كتشخيص. اللوحة تشوف رقمًا تحرّك؛ ما تشوف السبب، وكتابة «بسبب كذا» تحوّل
ارتباطًا إلى ادعاء.

| التنبيه | الحد |
|---|---|
| معدل التفعيل | نزول ≥ 10٪ عن الفترة السابقة |
| أخطاء الذكاء الاصطناعي | ≥ 5٪ من الاستدعاءات |
| المسار البديل | ≥ 5٪ من الطلبات |
| العودة بعد 7 أيام | نزول ≥ 10٪ |
| نسبة تعديل المتطلبات | ≥ 35٪ |

ما فيه تنبيه يشتغل على مؤشر غير متوفّر، ولا على نسبة محسوبة من صفر استدعاء.

---

## إضافة مؤشر جديد لاحقًا

الترتيب مقصود: الواجهة ما تعرف شيئًا عن Supabase.

1. أضف الحساب داخل `admin_analytics()` في `supabase/schema.sql`.
2. حوّله إلى `metric()` في `src/admin/analytics/client.js`.
3. اعرضه بـ `<KpiCard>` أو أحد مكوّنات `src/admin/components/`.

ولما يجي يوم يصير الإيراد حقيقيًا، الشغل كله في الخطوتين الأولى والثانية —
صفحة الإيراد نفسها ما تتغيّر ولا سطر.
